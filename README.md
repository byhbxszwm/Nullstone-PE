# NullStone

一个用 C++ / OpenGL ES 2.0 从零手写的 Minecraft 风格沙盒游戏，运行在 Android 上。

没有使用任何游戏引擎——所有渲染、地形生成、方块网格、相机、碰撞、UI 都是自己写的。

> 灵感来自 Minecraft PE 早期版本（0.6.x ~ 1.x）的架构思路，但代码是全新重写的。

---

## 功能

### 已实现

- [x] **程序化地形生成** — 基于 Perlin 噪声，多层八度叠加
- [x] **随机树木** — 噪声控制分布密度
- [x] **方块世界** — 单一大数组（128 × 64 × 128），无区块系统
- [x] **OpenGL ES 2.0 渲染** — 手写 vertex / fragment shader
- [x] **面剔除** — 只渲染暴露在空气中的面
- [x] **纹理图集** — Java 层自动拼接独立小图成 atlas
- [x] **第一人称相机** — 触摸拖动旋转，按键移动
- [x] **重力与跳跃** — 简易物理
- [x] **水平碰撞** — 撞墙会停
- [x] **射线拾取** — 准星指向的方块高亮
- [x] **挖方块** — 长按屏幕
- [x] **放方块** — 短按屏幕
- [x] **设置界面** — 渲染距离 / FOV / 灵敏度 / 音量

## 技术栈

| 层 | 技术 |
|----|------|
| 渲染 | OpenGL ES 2.0（手写 shader） |
| 语言 | C++11（native）/ Java（UI 层） |
| 编译 | Android NDK（`ndk-build`） |
| 最低版本 | Android 5.0（API 21） |
| 架构 | arm64-v8a / armeabi-v7a |
